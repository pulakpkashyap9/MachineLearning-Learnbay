# MachineLearning-Learnbay
These are the Machine Learning algorithms that I have learned via Learn Bay and Simplilearn.  This repository has all the files with the codes required for the alogorithms taught by Learn Bay
The files are as follows:
1. LEARNBAY: KNN with Cross Validation (Dataset: Classified Data)
2. LEARNBAY: KNN (Dataset: Iris)
3. LEARNBAY: Naive Bayes (Gaussian) with Grid Search CV (Dataset: Human Activity Recognition)
4. LEARNBAY: Logistic Regression with ROC and AUC (Dataset: Social Networks Ads)
5. LEARNBAY: Linear Regression with Regression Evaluation Metrics (Dataset: Advertising)
6. LEARNBAY: Support Vector Machine with Hyper-Parameter Tuning and GridSearchCV (Dataset: Voice)
7. LEARNBAYEnsemble Algorithms (Decison Tree, Random Forest, Ada Boost, Gradient Boosting, XG Boost) with Hyper-Parameter Tuning using Grid Search CV (Dataset: German Credit Data)
8. LEARNBAY: Clustering Algorithms: KMeans and Hierarchical (Dataset: Mall Cutomers)
